# Activation evaluation v3 semantics

The activation profile owns sampled decoding (`temperature: 0.8`, `top_p: 0.95`). The base configuration is read without modification. Each generation retains its deterministic seed; top-ups use disjoint seeds and can therefore produce additional canonical tactics. Weights remain frozen.

Generation exposes `GenerationResult(text, processed_token_positions, diagnostic)` through `generate_with_usage`. The existing `generate` method still returns text. Both backends meter actual input positions at the first decoder block, including chunked prefill and every cached decode step that executes. Invisible special tokens are counted if processed; a predicted final EOS that never enters another forward does not create an invented forward. Text is never decoded and retokenized to reconstruct generation usage. Admission uses the generation encoder's prompt IDs, including its special-token policy, plus the maximum decode allowance. Teacher-forced scoring retains its existing accounting.

The equal-compute ceiling includes selected-candidate preparation, final generation, and any new post-selection causal diagnostics. Continuation can run only when its conservative next-call allowance fits the remaining ceiling. Exhaustion preserves immediate rescue progress but cannot claim a later solve. Equal-tactic continuation retains its fixed Lean cap and separately reported usage. Proof-state embedding diversity remains an observational diagnostic rather than a solve input.

The primary causal outcome is now separately reported for selected-arm immediate-rescue tactics actually submitted to Lean, including rejections. Existing union scores are reused. New final tactics receive neutral/contextual captures and a patch score after the winner freezes; their cost increases the selected condition's ceiling and is recorded under `verified_tactic_*` charges. The report gives measured/submitted coverage and keeps this outcome separate from the union-wide candidate selection score. Conventional continuation tactics are outside this causal metric.

The shuffled arm takes a deterministic compatible source/alignment/transfer package from another problem when it has different reasoning. Otherwise it rotates proof roles and rebuilds the explanatory operation, invariant, limitation, premises, reasoning steps and predicted next subgoal from that rotation. The selected target transfer is not retained. No reference proof or verifier outcome enters either operation.

Artifact schema v3 deliberately rejects v1/v2 resumes: those runs used different generation accounting, decoding and continuation semantics. Start a new run; existing artifacts remain untouched. Within v3, the process lock and bound manifest still govern all writes. Collection records each successful model result in an atomic private working checkpoint and each completed cell in a recoverable checkpoint. Resumption checks operation requests and result hashes, reuses durable work, completes collection, and only then freezes calibration and selection. A process death after a model call but before its result is durably published can require repeating that uncommitted call.

Working collection checkpoints temporarily retain vectors because cross-fit calibration is unfinished. Once the frozen checkpoint is published they are removed, and finalization repeats cleanup if publication was interrupted. Default published frozen/trial records retain activation and patch-delta summaries/hashes; full diagnostic vectors require `persist_full_activations`. Each Phase B cell commits all eight rows by atomic replacement, so an interrupted commit leaves the prior journal intact. An uncommitted Phase B cell is evaluated again from its frozen selection. Anchor preparation before the manifest is sealed is outside the collection-resume boundary.

Progress per Lean call uses eligible immediate-rescue progress divided by eligible immediate-rescue calls. Continuation calls and total completions remain separate. These changes have unit and fake end-to-end validation; they do not constitute a new real-model experiment or validate an earlier diagnostic smoke run.
