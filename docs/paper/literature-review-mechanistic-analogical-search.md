# Mechanistic Literature Review: From Autoregressive Decoding to Analogical Search

**Working review for _Directed Analogical Exploration in Frozen Language Models_**
**Literature checked through October 18, 2026**

## Executive synthesis

The relevant research question is not primarily whether a language model can state an
analogy. It is whether the standard Transformer decoding process can be replaced or
augmented by a computation that **searches over analogical world models before committing
to a token or action**.

A conventional decoder implements one principal loop: transform the current context into a
next-token distribution, sample or select a token, append it, and repeat. Chain-of-thought
extends the loop by turning intermediate computation into more tokens, but each token still
commits the model to one visible trajectory. Tree search methods relax that commitment by
running multiple textual trajectories outside the model. Latent-reasoning methods instead
repeat computation over hidden states before emitting text. Classical analogy architectures
explicitly construct and compare relational mappings, but they do not inherit the breadth
of a pretrained language model.

The literature therefore supplies nearly all the parts of an analogical search mechanism,
but not their integration:

- **recurrent latent computation** from Universal Transformers, continuous-thought models,
  and depth-recurrent language models;
- **exploration–exploitation control** from Tree of Thoughts, Monte Carlo tree search,
  verifier-guided reasoning, and language-agent search;
- **relational mapping** from the Structure-Mapping Engine, LISA, Copycat, and recent
  geometric analyses of analogy in Transformers;
- **model-native task directions** from function vectors, concept vectors, activation
  patching, and representation engineering; and
- **grounded selection** from proof assistants, program verifiers, simulators, and process
  or outcome reward models.

No established architecture yet uses source–target mappings as the primitive branch in a
recurrent latent search, allocates compute between novel and promising mappings, and exposes
the selected mapping in a human-readable form before action. That is the specific gap for a
mechanism we can call an **Analogical Deliberation Core**.

## 1. Why ordinary decoding is the wrong computational object

An autoregressive Transformer decoder computes

\[
p(x_{t+1}\mid x_{\le t}) = \operatorname{softmax}(W h_t),
\]

selects one continuation, and feeds that choice back into the next step. All of the model's
internal computation for the current step is compressed into a distribution over vocabulary
items. This architecture is exceptionally effective for sequence modeling, but it creates
three mismatches with analogical reasoning.

First, analogy initially requires **parallel ambiguity**. Several source domains and several
role mappings may be plausible. Early collapse to one textual explanation can destroy useful
alternatives. Second, analogy requires **re-representation**: the target and source may need
to be reorganized before their shared structure becomes visible. Appending more tokens does
not guarantee that the underlying representation changes in the right way. Third, analogy
requires **global evaluation**. The best source is not necessarily the one that makes the
next sentence most probable; it is the one whose transferred relations produce valid and
useful target consequences.

Chain-of-thought prompting does not fundamentally remove these constraints. It gives the
decoder more serial state and may elicit useful intermediate computations, but it still
materializes one linguistic path. Moreover, stated rationales can be causally unfaithful to
the answer [Paul et al., 2024]. A mechanistic account of analogical reasoning should thus
distinguish computation from narration. Language can remain the inspection and communication
surface without serving as the only substrate in which search occurs.

## 2. External search around a decoder

### 2.1 Tree of Thoughts

Tree of Thoughts is the clearest demonstration that next-token decoding is not the only
possible inference procedure for a pretrained LM. Instead of committing to one chain, the
system generates coherent textual “thoughts,” scores intermediate states, retains promising
branches, and backtracks when necessary [Yao et al., 2023]. It produced large gains on tasks
whose structure rewards lookahead and search.

Mechanistically, however, Tree of Thoughts leaves the decoder intact. The tree exists in an
external controller; nodes are strings; proposals and values are typically generated by the
same language model. This makes the method a useful architectural control for analogical
search but not an implementation of it. The branches are arbitrary reasoning continuations,
not explicit source–target mappings, and the value function need not distinguish structural
transfer from surface plausibility.

### 2.2 World-model planning and MCTS

Reasoning via Planning (RAP) recasts inference as model-based planning. An LLM proposes
actions, predicts successor states as a world model, and uses Monte Carlo tree search to
balance exploration and exploitation [Hao et al., 2023]. Language Agent Tree Search adds
environment feedback, self-reflection, and an LM-based value function in an MCTS loop [Zhou
et al., 2024]. VerMCTS applies related ideas to formally verified program synthesis [Brandfonbrener
et al., 2024].

These systems provide a direct formal template. At search node \(s\), a controller can select
candidate \(a\) using a PUCT-style rule:

\[
a^* = \arg\max_a \left[
Q(s,a) + c_{\mathrm{puct}}P(a\mid s)
\frac{\sqrt{N(s)}}{1+N(s,a)}
\right].
\]

The first term exploits candidates with high estimated return; the second explores
under-visited candidates favored by the proposal policy. For analogical search, \(a\) should
not initially be a token or ordinary reasoning step. It should be a structured object:

\[
a = (A, M, \tau),
\]

where \(A\) is a source domain, \(M\) a source–target role mapping, and \(\tau\) a proposed
transferred transformation. Rollouts then evaluate target consequences implied by the
mapping.

The limitation of existing LM–MCTS systems is self-evaluation. If the same model proposes a
branch, predicts its successor, and assigns its value, correlated errors can dominate the
tree. Formal verification, simulation, or a separately trained critic is especially
important for analogy because persuasive source stories can conceal invalid transfers.

### 2.3 Learning the search trace

Searchformer takes a different route: it trains a Transformer to generate search dynamics
derived from A*, then compresses those traces into more efficient planning procedures
[Lehnert et al., 2024]. The result suggests that explicitly supervising search can enable a
smaller model to outperform direct plan prediction. Quiet-STaR likewise trains token-local
internal rationales that improve prediction of future text, particularly difficult tokens
[Zelikman et al., 2024].

These methods show that search behavior can be amortized into a neural policy. For an
analogical core, verified search traces could become training data: which sources were
called, which mappings failed, which counterexamples forced abandonment, and which transfer
produced a useful state. The long-term system could learn a fast analogical proposal policy
while preserving explicit search for difficult cases.

## 3. Latent computation inside the decoder

External tree search is interpretable but expensive because every branch is tokenized and
reprocessed. A second research line increases computation before or between emitted tokens.

### 3.1 Universal and depth-recurrent Transformers

The Universal Transformer replaces a stack of distinct layers with a recurrent
self-attention transition applied repeatedly across depth. Adaptive Computation Time allows
different positions to halt after different numbers of refinement steps [Dehghani et al.,
2019]. This is the basic architectural precedent for separating parameter count from
computation depth.

Geiping and colleagues scale this idea to a 3.5B-parameter language model. Their recurrent
block can be iterated more times at inference, producing improved reasoning performance
without generating additional chain-of-thought tokens [Geiping et al., 2025]. The work is
particularly relevant to small models: shared parameters support substantially greater
effective depth at test time, and simple items settle earlier than difficult reasoning
problems.

The recurrence is nevertheless undirected. More depth gives the hidden state additional
opportunities to refine, but the architecture does not explicitly maintain multiple source
hypotheses or decide which relational mapping to explore. An analogical core would turn the
recurrent transition into a population update over candidate mappings rather than repeated
processing of a single undifferentiated state.

### 3.2 Continuous thought

COCONUT feeds the model's final hidden state back as a continuous input embedding, allowing
reasoning steps that do not pass through discrete language tokens [Hao et al., 2024]. The
authors report behavior consistent with multiple candidate paths being represented before
the model commits to an answer. This is an appealing substrate for analogy: a superposed
latent state can retain several mappings that would be awkward to verbalize one at a time.

Continuous states create an interpretability and control problem. It is difficult to know
whether a recurrent vector represents multiple useful alternatives, diffusion around one
idea, or unstable dynamics. The relevant lesson is not that continuous thought already
implements breadth-first search. It is that hidden-state recurrence makes nonlinguistic
deliberation possible. An analogical mechanism needs explicit slots, correspondence
matrices, or particles so that distinct hypotheses remain identifiable.

### 3.3 Pause tokens and implicit computation

Pause-token methods give a Transformer additional forward-pass computation before an
answer, while Quiet-STaR interleaves sampled rationales with ordinary prediction [Goyal et
al., 2024; Zelikman et al., 2024]. These approaches show that useful compute can be inserted
without requiring the final visible response to contain every intermediate operation.

They do not define what the extra compute should do. For analogy, the inserted computation
should be trained against structural objectives: retrieve diverse sources, bind roles,
predict target transitions, check invariances, and halt when one mapping has sufficient
verified or predicted value.

## 4. Classical analogy architectures as design specifications

Recent language-model systems often use “analogy” to mean relevant examples. Classical
computational models are more precise about the operation an analogical decoder would need
to perform.

### 4.1 Structure-Mapping Engine

The Structure-Mapping Engine constructs local matches between predicates, combines
consistent matches into global interpretations, enforces one-to-one correspondence and
parallel connectivity, and scores systematic relational structures [Falkenhainer, Forbus,
and Gentner, 1989]. SME is not a retrieval model or a neural architecture, but it supplies a
clear contract for a mapping head:

- represent entities separately from relations;
- prefer relation-preserving correspondences over attribute matches;
- enforce mapping consistency;
- favor connected systems of higher-order relations; and
- emit candidate inferences licensed by the mapping.

In a differentiable system, a soft correspondence matrix \(C\) can approximate these
constraints. If source roles are \(u_i\) and target roles \(v_j\), an alignment module can
produce

\[
C_{ij} = \operatorname{Sinkhorn}
\left(\frac{q(u_i)^\top k(v_j)}{\sqrt d} + B_{ij}^{\mathrm{rel}}\right),
\]

where Sinkhorn normalization encourages near-bijective matching and
\(B^{\mathrm{rel}}\) scores relational compatibility. Higher-order consistency can be
trained by requiring mapped edges and transformations to predict one another.

### 4.2 LISA and dynamic role binding

LISA represents objects and predicates as distributed activation patterns while using
temporal synchrony to bind roles into propositions [Hummel and Holyoak, 1997]. Its central
contribution is the separation of distributed content from explicit relational binding.
Standard Transformer attention also binds information dynamically, but it does not guarantee
stable role identity across source and target domains. LISA suggests that an analogical core
needs dedicated role slots or binding operations, not only vector similarity.

This matters for the proposed proof setting. The propositions \(P\), \(Q\), and \(P\to Q\)
must map to distinct source roles even if their text embeddings are similar. A relation such
as “resource requires input” must bind the prerequisite to \(P\) and the resulting capability
to \(Q\); reversing these bindings produces a fluent but useless analogy.

### 4.3 Copycat and computational temperature

Copycat is the closest classical precedent for explore/exploit analogical search. It uses
many small stochastic processes, a dynamically activated conceptual network, mutable
representations, and a global “temperature” that controls randomness [Hofstadter and
Mitchell, 1995]. Early in a run, weak structure supports broad exploration and conceptual
slippage. As coherent structures accumulate, temperature falls and processing becomes more
deterministic.

The architectural lesson is deeper than adding a novelty bonus. Representation and search
co-evolve. A promising mapping changes which concepts are active, which in turn changes the
next mappings likely to be considered. This is absent from ordinary beam search, where the
meaning of a node is fixed by its token prefix.

A modern analogical controller could implement candidate-specific temperature:

\[
T_t = T_{\min} + (T_{\max}-T_{\min})
\sigma(\alpha U_t - \beta K_t),
\]

where \(U_t\) is uncertainty or disagreement among candidate mappings and \(K_t\) is
coherence or accumulated verifier support. High uncertainty expands source diversity;
growing coherent evidence shifts compute toward exploitation. A countermodel raises
temperature locally and suppresses the failed source family.

## 5. Evidence that Transformers contain usable relational machinery

An analogical core is plausible only if pretrained Transformers already encode useful
relations and task transformations.

### 5.1 Function and concept vectors

Function vectors identify compact activation patterns that causally induce an in-context
task across some changes of context [Todd et al., 2024]. They show that model behavior can
be controlled at the level of a task transformation rather than individual tokens.

Yet causal strength is not equivalent to abstraction. Opiełka, Rosenbusch, and Stevenson
find that function vectors for the same task can be nearly orthogonal across output formats.
More invariant concept vectors can be identified, but the attention heads supporting
invariance and those supporting strong causal effects overlap surprisingly little
[Opiełka, Rosenbusch, and Stevenson, 2026].

For architecture design, this argues against a single scalar analogy score. Candidate state
should have at least two axes:

- **invariance:** does the relation persist across paraphrase, symbol substitution, and
  output format? and
- **control:** does activating or patching it change the correct target transition?

The best branch lies on a Pareto frontier. A highly causal but format-bound vector may be a
shortcut; a highly invariant but causally inert vector may be a detector rather than a
reasoning operator.

### 5.2 Structural alignment and functor-like transfer

Minegishi and colleagues train controlled Transformers on categories sharing relational
structure. Analogical generalization emerges when the categories become geometrically
aligned and Transformer layers learn a functor-like operation that transfers an entity to
its counterpart. Their experiments separate structural alignment in embedding space from
application of the cross-category transformation [Minegishi et al., 2026].

Lee and colleagues find a related division in pretrained LLMs: relational information can
be present while application to the target fails; patching critical representations can
partially restore transfer [Lee et al., 2026]. These results support a two-stage analogical
operator:

\[
\text{align source and target structure}
\quad\rightarrow\quad
\text{apply mapped transformation}.
\]

They also explain why embedding retrieval alone is inadequate. Retrieval may find a source
with compatible geometry, but a separate routing operation must write the transferred
relation into the target workspace.

### 5.3 Latent geometric approaches

Recent Encoder–Reasoner–Decoder work shows that consistent relation vectors can solve
bounded analogical tasks when the latent space is explicitly regularized so that source
differences correspond to target transformations [Dats, 2026]. Vector-symbolic architectures
likewise provide binding and unbinding operators for structured computation in high-
dimensional spaces [Schlegel, Neubert, and Protzel, 2021].

These approaches are useful component models rather than complete language reasoners. They
suggest a way to represent analogical actions: not as source prose, but as a transformation
operator plus a correspondence matrix. Natural language is decoded only when the mapping
must be inspected or communicated.

## 6. Proposed architecture: an Analogical Deliberation Core

The literature points to a concrete replacement for ordinary one-path decoding. The system
can retain a pretrained encoder/decoder for language input and output while inserting a
recurrent search core between context encoding and final action emission.

### 6.1 State

At deliberation step \(t\), maintain

\[
\mathcal W_t = (z_t, R, \mathcal H_t, \mathcal A_t, \mathcal M_t),
\]

where:

- \(z_t\) is the current target-state representation;
- \(R\) is the supplied target rule set;
- \(\mathcal H_t\) is verified transition history;
- \(\mathcal A_t\) is a population of active analogy particles; and
- \(\mathcal M_t\) is episodic memory of successful and abandoned mappings.

Each analogy particle is

\[
a_i=(s_i,C_i,g_i,\hat z_i,q_i,n_i),
\]

with a source representation \(s_i\), role-correspondence matrix \(C_i\), transferred
operator \(g_i\), predicted target state \(\hat z_i\), value statistics \(q_i\), and visit
count \(n_i\).

### 6.2 Modules

**Relational encoder.** Convert the target and its few rules into entity, role, relation,
and constraint slots. This can be a Transformer with object-centric or typed memory tokens,
but the loss must preserve role structure under paraphrase.

**Source proposal kernel.** Produce candidate source structures from parametric memory,
retrieved episodes, and sampled latent transformations. Proposals should be diverse in
relational geometry, not merely lexical domain.

**Mapping head.** Construct \(C_i\) under approximate one-to-one and relational-consistency
constraints inspired by SME and LISA. It should be possible to render the result as an
explicit role table.

**Transfer/world-model head.** Apply the mapped source operator to predict target
consequences. This head supplies imagined successor states for cheap rollouts.

**Critic and verifier interface.** Estimate progress, rule consistency, uncertainty, and
expected verifier outcome. When an exact verifier is available, it overrides the learned
critic for visited states.

**Explore/exploit controller.** Allocate recurrent steps among particles. A candidate score
could be

\[
U_i = \hat Q_i
+ c_1 P_i\frac{\sqrt{\sum_j n_j}}{1+n_i}
+ c_2 D_i^{\mathrm{struct}}
+ c_3 I_i^{\mathrm{invariant}}
- c_4 F_i^{\mathrm{rule}}
- c_5 \kappa_i^{\mathrm{compute}},
\]

where \(D_i^{\mathrm{struct}}\) rewards a relationally distinct source, invariance measures
stability across target reformulations, rule failure penalizes predicted violations, and
compute cost prevents endless contemplation. Early search emphasizes the prior and diversity
terms; later search exploits verified or high-value branches.

**Halting and emission head.** Stop when one candidate has sufficient value margin and low
uncertainty, when the verifier accepts a transition, or when the compute budget expires.
Only then decode a tactic, plan step, or natural-language answer. The system separately
decodes a compact source–mapping–transfer record for human inspection.

### 6.3 Recurrence

One recurrent cycle performs:

1. call or mutate source candidates;
2. align roles and relations;
3. predict mapped target transitions;
4. score novelty, invariance, causal effect, and rule consistency;
5. expand, merge, suppress, or abandon particles;
6. query an exact verifier for selected actions when affordable; and
7. update the workspace and computation allocation.

This is neither ordinary beam search nor a purely continuous hidden loop. Its recurrent
state is a structured population of analogical hypotheses. It resembles MCTS in resource
allocation, Copycat in temperature-sensitive conceptual activation, SME in mapping
constraints, and a recurrent-depth Transformer in its ability to spend variable compute
without emitting tokens.

## 7. Training objectives

A practical system need not be trained end to end from scratch. The components admit a
staged program.

### 7.1 Structural pretraining

Train on synthetic paired domains with known relational isomorphisms and controlled
distractors. Objectives should recover role correspondences, mapped transformations, and
candidate inferences. Minegishi et al.'s controlled category tasks provide one template;
SME can generate additional supervision.

### 7.2 Invariance training

Paraphrase entities, permute symbols, alter presentation order, and switch output formats
while preserving relational structure. Contrastive losses should bring representations of
the same relation together and separate surface matches with incompatible structure.

### 7.3 Search-policy learning

Run broad verifier-guided search offline. Distill successful traces into a proposal prior
and value model, including negative supervision from seductive but invalid mappings.
Searchformer and STaR-style bootstrapping show how expensive search can train a faster
policy.

### 7.4 Causal-use objective

Do not reward only decodability of a relation. Patch or ablate candidate representations
and require a predictable change in the mapped action distribution. This trains the mapping
to be used, not merely stored.

### 7.5 Budgeted halting

Optimize accuracy jointly with a ponder cost. Adaptive Computation Time and recurrent-depth
work show that variable compute is learnable, but halting can collapse to shallow solutions.
Training should randomize available depth, impose minimum deliberation on hard examples, and
evaluate extrapolation beyond trained recurrence counts.

## 8. What would count as replacing the decoder?

There are three increasingly strong implementations.

### Level 1: Controller around a frozen decoder

The existing LLM proposes explicit analogies and tactics; an external MCTS or bandit
controller allocates calls; a verifier supplies outcomes. This is achievable now and is the
right experimental baseline. It tests the search policy but still pays token-generation
cost for every branch.

### Level 2: Latent analogical adapter

Freeze most model weights and add recurrent analogy slots, a mapping head, a value head, and
a halting controller at middle-to-late layers. Candidate hypotheses evolve in latent space;
only selected mappings are decoded. This tests whether analogical deliberation can be
retrofitted into a small pretrained model without full fine-tuning.

### Level 3: Native analogical decoder

Pretrain a model whose basic inference cycle is propose–map–simulate–verify–update, with
language emission as one action available after deliberation. Recurrent depth and memory
slots replace a fixed stack followed immediately by vocabulary projection. This is the
strong architectural thesis, but it should follow evidence from Levels 1 and 2.

“Replacing the decoder” should therefore not mean discarding Transformers entirely. It
means replacing the **token as the unit of deliberative state transition** with an
analogical hypothesis, while retaining attention and learned representations as useful
implementation machinery.

## 9. Key risks and falsifiers

**Search without abstraction.** The controller may simply sample more solutions. Shuffled
mapping controls and equal-compute comparisons must show that relational structure matters.

**Latent collapse.** All particles may converge to lexical variants of one source. Diversity
must be measured over relation graphs or induced transformations, not embedding distance
alone.

**Self-verification loops.** A model that proposes, simulates, and scores its own mapping may
amplify shared errors. Exact verification or separately trained critics are essential.

**Causal but non-invariant shortcuts.** Strong activation interventions may exploit
format-specific features. Every claimed analogical operator should be tested across
paraphrase, symbol permutation, and output format.

**Inert interpretability.** The decoded mapping may be readable but causally irrelevant.
Removing or swapping it should alter the selected action in predicted ways.

**Compute inefficiency.** A small recurrent model may use more FLOPs than a larger direct
model. Report both equal-verifier and equal-total-compute results.

**Recurrence instability.** Additional loops may degrade representations or enter cycles.
Evaluate performance as a function of recurrence depth and include learned or verifier-based
halting.

The architecture is falsified in its strong form if a relation-aware controller provides no
advantage over compute-matched generic tree search, if explicit mappings do not predict
intervention effects, or if benefits disappear under surface-form perturbation.

## 10. Position relative to the literature

The proposed Analogical Deliberation Core is not simply Tree of Thoughts with analogy
prompts. Its search nodes are latent relational mappings, not free-form text. It is not
simply COCONUT or recurrent depth, because recurrence maintains a population of explicit
hypotheses with an exploration policy. It is not simply SME, because sources and
transformations are induced from a pretrained neural representation rather than supplied as
complete symbolic graphs. It is not simply representation engineering, because activation
directions are used to propose and test structured target transitions rather than to steer
a fixed trait.

The novel synthesis is:

\[
\text{latent relational memory}
+ \text{explicit role binding}
+ \text{exploration/exploitation search}
+ \text{variable recurrent compute}
+ \text{external verification}.
\]

That synthesis directly addresses the motivating question. A small model given a few target
rules would not need to contain a complete target-domain solver. It would need a reusable
proposal policy, a model-native library of relational transformations, and a controller that
can discover which transformation makes verified progress. Learning the new domain then
means constructing a temporary search space, not updating the weights.
